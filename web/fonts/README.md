# Locally hosted brand fonts

Latin variable WOFF2 files from @fontsource-variable/inter 5.3.0 and @fontsource-variable/manrope 5.3.0, obtained from npm. SIL Open Font License texts accompany the files. Next/font/local preloads these on the same origin, with swap and metric-adjusted Arial fallbacks. No Google Fonts request is made by visitors or at build time.

Manrope is for headings and metrics; Inter is for body/interface text. Add language subsets deliberately if coverage expands beyond Latin. Preserve licenses when updating; record the version and update the asset hash manifest.
