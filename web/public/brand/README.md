# Approved ParcelSavvy logo assets

These SVGs are exact vector extracts of page 8 of docs/brand/ParcelSavvy_Brand_Guide.pdf (approved Option 1), not a redraw. The wordmark is retained as paths; never rebuild it with live type. The extraction retains the original colors/composition and adds external clear space of 12 PDF units (at least one pane height).

- parcelsavvy-logo-horizontal.svg — 623×157, primary full-color lockup on white. Use BrandLogo, at least 140 CSS px wide. Intrinsic dimensions reserve layout space.
- parcelsavvy-logo-mark.svg — 115×97, approved standalone full-color mark on white. At least 24 px wide; used as favicon.
- parcelsavvy-logo-mark-reversed.svg — 115×97, the approved standalone white/blue/coral mark on navy extracted from the same page.

Do not recolor, rotate, stretch, add shadows/outlines, or crop away the clear space. Use the horizontal logo on a white header. An approved **reversed horizontal lockup** and the designer's original editable master are not supplied; do not fabricate them. A separately approved simplified favicon below 24 px may improve tiny browser icons; the current favicon uses the supplied mark proportionally.

BrandLogo alt is “ParcelSavvy”; the home link uses “ParcelSavvy home”. Use empty alt only when equivalent visible text makes a repeated decorative logo redundant. Approved assets are exempt from the UI raw-color scanner and protected by docs/brand/assets.sha256.json.
