# PAR-19: neighborhood annual-analysis contract

Repository base: `7a657af` (merged PAR-17/18). This change is an additive data layer for PAR-20; existing neighborhood/print routes still use v4 until that UI issue is implemented.

## Consumer contract

Call `getNeighborhoodAnalysis(id, season)` from `web/src/lib/supabase/neighborhood-analysis.ts`, passing the same `activeSeason(await getSeasonCalendar())` context used by the overview (or null when unavailable). Both redesigned page and print route must consume this result. Never recalculate formulas in components.

- `data`: existing validated Neighborhood shape plus `annual_periods`, one earliest eligible preliminary and latest certified release per available year. Rows are restricted to the current v4 cohort; absent, ineligible or changed-neighborhood observations never become zero values.
- `analysis.current` / `currentSummary`: actual selected year/stage and preserved current metrics, entities, distributions, multiplier and population metadata (multiplier remains on `data.market_adjustment`).
- `analysis.latestOutcome` / `outcomes`: chronologically valid completed preliminary/certified pairs, with explicit cap-source release, all-home and conditional denominators, protest/inferred-reduction participation and protested/non-protested summaries. May refer to a previous year during preliminary/protest season.
- `certifiedChanges`: change of medians using the same matched properties in both years.
- `preliminaryChanges`: median individual percentage change and share receiving a higher proposal.
- `carryForward`: at least 10% reduced from P to C, then N >= P / C < N < P / N <= C. Exact whole-dollar arithmetic at the inclusion boundary, without rounding or tolerance. Includes matched/base/excluded/reduced counts and each bucket's numerator/denominator.
- `coverage`: per-release eligibility/exclusion/missing counts. `smallSample` is true for nonzero pattern denominators under 10; the UI should lead with counts in that case. A zero denominator produces null percentage.

The RPC is `public.property_neighborhood_analysis(text,text,integer)`. It is SECURITY INVOKER with empty search_path, inherited RLS, a private-schema visibility-checked helper returning only dataset-level baseline eligibility, no raw-table grants or privileged browser key, 10,000-home/100-release bounds and a 25-second database statement limit. The existing client timeout remains unchanged. It makes bounded profile reads per canonical release, not client requests per home. Supplemental/interim snapshots do not become preliminary baselines. Available years and season settings select stages, not hardcoded 2025/2026 rules.
